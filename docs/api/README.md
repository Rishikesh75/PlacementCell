# PlacementCell API documentation

The OpenAPI specification is generated from the Spring Boot backend by the
GitHub Actions workflow at `.github/workflows/openapi-docs.yml`.

## View or download the specification

- **OpenAPI JSON:** [openapi.json](./openapi.json)
- **Swagger Editor:** open [editor.swagger.io](https://editor.swagger.io/) and import the JSON file.
- **Postman:** Import the JSON file as an API definition to generate a collection.

## How it is refreshed

The workflow runs when backend source/configuration changes are pushed or included
in a pull request. It starts temporary PostgreSQL and MongoDB services, builds and
starts the backend, then downloads `/v3/api-docs`.

- On a branch push, the workflow commits an updated `openapi.json` to that branch
  when the generated specification has changed.
- On a pull request, the workflow uploads the generated JSON as a downloadable
  Actions artifact; it does not write back to the pull-request branch.
- The Actions artifact is retained for 30 days.

## Important

This file documents the API contract; it does not host or run the backend.
To execute API requests, point Postman or another client at a running backend
environment. The OpenAPI file generated by CI is a snapshot of the code at the
commit that triggered the workflow.
